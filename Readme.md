# Blesk
[Ligntning Network] node.

## Requirements
- [Docker Compose]

## Usage
```bash
docker compose up
```

## Components
- [TOR]
- [Bitcoin Core]
- [Electrs]
- [BTC RPC Explorer]
- [Samourai Dojo] with [Nginx] reverse proxy
- [LND]
